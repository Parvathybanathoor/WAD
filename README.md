# Student Information System

A simple and user-friendly **Student Information System** developed using **HTML, CSS, and JavaScript**.

## Features

* Enter student username
* Enter roll number
* Select branch
* Display student details
* Clear entered details
* Edit student information
* Input validation

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Enter the student details.
4. Click **Display** to view the information.

## Project Preview

The application provides a simple form where users can enter student information and display it dynamically.
